Asoldi - Website Pricing Calculator (local test build)

Website services only (no marketing tier yet). Not styled for production - for testing price logic before going live.

How this works now: Starter / SEO / Nettbutikk are fixed packages (999 / 1 499 / 1 999 at 5 pages). Taking a service out of a named package does not lower the price. Add-ons on top of a package use Skreddersydd unit prices. Skreddersydd is à la carte at those custom prices (nettbutikk-funksjonalitet 900 kr, ubegrenset redigering 1 000 kr, blogg 400 kr, …). Blogg-integrasjon is included in every named package (package price stays 999 / 1 499 / 1 999). On Skreddersydd it is 400 kr if ticked. Layout/webdesign is always on and free. Floor on Skreddersydd is still 999 kr/mnd. Page scaling is +10% of that service’s own base per page beyond 5, for hosting, SEO, flerspråklig and dedicated server. Ubegrenset innholdsendringer is 1 000 kr/mnd; on one-time payment it covers the first 6 months only (×6, not ×9). Edit the DATA object at the top of the <script> tag to change numbers.
